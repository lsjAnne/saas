# 部署与环境配置说明

| 文档名称 | 文档类型 | 当前版本 | 适用对象 | 主要读者 | 维护状态 |
| --- | --- | --- | --- | --- | --- |
| 部署与环境配置说明 | 架构/部署设计 | v2.0 | 环境准备、部署实施、联调、上线、交付 | 后端、运维、测试、平台运营、实施 | 已整理 |

## 1. 文档目的
本文档定义平台的环境分层、部署组件、配置分类、构建基线、联调网络口径和交付要求，作为标准 SaaS 版与私有化版的软件部署基线。

## 2. 环境分层
| 环境 | 主要用途 | 关键要求 |
| --- | --- | --- |
| 开发环境 | 本地开发、自测、快速验证 | 可重置、可局部 Mock、支持快速构建 |
| 联调环境 | 前后端、第三方、模型能力联调 | 固定账号、稳定种子数据、基础审计可用 |
| 测试环境 | 回归验证、自动化执行、验收预演 | 数据可复用、权限完整、日志可追踪 |
| 预发环境 | 上线前验证 | 配置尽量接近生产、禁止临时绕过鉴权 |
| 生产环境 | 正式业务运行 | 安全注入、备份、监控、告警、审计全部启用 |

## 3. 标准交付形态
### 3.1 SaaS 标准版
- 平台统一托管部署。
- 多租户共享应用与基础设施。
- 通过租户、组织、权限、配额和审计隔离。

### 3.2 私有化版
- 单客户独立环境部署。
- 配置、数据、监控、备份和访问控制独立管理。
- 与标准版共用统一业务模型、接口模型和审计模型。

## 4. 标准部署组件
| 组件 | 职责 | 标准 SaaS 版 | 私有化版 |
| --- | --- | --- | --- |
| Web 前端 | 租户业务前台与平台后台入口 | 必选 | 必选 |
| API 主服务 | 主业务接口、平台接口、开放接口 | 必选 | 必选 |
| Job Worker | 定时任务、巡检、对账、清理、补偿 | 必选 | 必选 |
| Callback Worker | 外部回调消费、重试、补偿 | 必选 | 按集成场景启用 |
| AI Worker | 模型异步生成、评测、脚本任务 | 按能力启用 | 按能力启用 |
| MySQL | 主业务库 | 必选 | 必选 |
| Redis | 缓存、幂等、会话短状态 | 必选 | 必选 |
| MQ | 异步削峰、通知、回调解耦 | 按业务能力启用 | 按业务能力启用 |
| 对象存储 | 素材、导出文件、附件 | 按业务能力启用 | 按业务能力启用 |
| 观测栈 | 日志、指标、告警、追踪 | 必选 | 必选 |

## 5. 环境拓扑要求
### 5.1 标准运行拓扑
```text
Browser / Admin Console
        |
     Web Frontend
        |
      API Gateway / API Service
        |
  -----------------------------------------
  |           |            |               |
 MySQL      Redis        MQ        Object Storage
  |           |            |               |
 Job Worker  Callback Worker  AI Worker  Export / Asset Service
        |
 Observability Stack
```

### 5.2 拓扑控制要求
- 平台后台与租户业务前台必须逻辑分区。
- 平台侧接口、租户侧接口、开放接口、回调接口必须按域分层。
- 审计日志、导出文件、缓存 Key、异步任务都必须带 `tenant_id`。

## 6. 配置分类
### 6.1 应用配置
- 服务端口
- 环境标识
- 日志级别
- 线程池参数
- Feature Flag 开关

### 6.2 数据配置
- MySQL 连接
- Redis 连接
- MQ 连接
- 对象存储连接

### 6.3 平台配置
- 电商平台授权参数
- 供应商平台接入参数
- Webhook 签名参数
- 插件与开放平台配置

### 6.4 模型配置
- 模型服务地址
- 模型名称
- 超时时间
- 降级策略
- 审核与熔断策略

### 6.5 治理配置
- 默认利润阈值
- 风险等级阈值
- 自动履约开关
- 导出保留时长
- 停服与退租窗口期

## 7. 配置治理原则
- 业务参数与环境参数分离。
- 敏感信息通过环境变量、密钥管理系统或部署平台注入。
- 正式交付文档不记录真实密码、密钥、令牌和主机信息。
- 配置变更必须留痕、可回滚、可审计。
- 私有化版允许客户自管密钥，但不允许修改核心审计口径。

## 8. 当前工程运行基线
### 8.1 持久化策略
- 默认运行模式：`jdbc`
- 本地开发与自动化测试：优先使用 H2
- 联调和正式环境：使用 MySQL

### 8.2 已落地 profile
- `default`：本地快速开发与单机验证
- `db-direct`：直连联调数据库与缓存
- `tunnel-local`：本地通过 SSH 隧道接入远端数据库与缓存
- `server-local`：应用直接部署在远端主机本机运行

## 9. 构建与启动基线
### 9.1 工具要求
- JDK：21
- Maven：3.9.x
- 禁止使用 Java 8 运行当前工程

### 9.2 本地构建基线
```powershell
$env:JAVA_HOME='D:\JDK'
$mavenHome='D:\maven\apache-maven-3.9.12'
$env:MAVEN_HOME=$mavenHome
$machinePath=[System.Environment]::GetEnvironmentVariable('Path','Machine')
$userPath=[System.Environment]::GetEnvironmentVariable('Path','User')
$env:Path="$env:JAVA_HOME\bin;$mavenHome\bin;$machinePath;$userPath"
mvn test
```

### 9.3 启动口径
- 本地开发默认使用 `default` 或 `tunnel-local`
- 联调环境使用固定 profile 和受控网络
- 预发与生产环境统一通过部署平台注入 profile 与密钥

## 10. 联调与网络基线
### 10.1 联调顺序
1. 本地默认环境自测
2. 联调环境固定数据验证
3. 通过 SSH 隧道接入远端数据库或缓存
4. 直接远端部署验证

### 10.2 SSH 隧道标准口径
```bash
ssh -L 13306:127.0.0.1:3306 -L 16379:127.0.0.1:6379 <user>@<host>
```

### 10.3 tunnel-local profile 使用方式
```bash
--spring.profiles.active=tunnel-local
```

## 11. 部署前检查清单
- JDK 与 Maven 版本符合要求
- profile 与环境标识正确
- 数据库、Redis、MQ、对象存储连接参数已注入
- 审计日志、导出目录、对象存储路径可写
- Webhook 回调地址、开放平台密钥和通知配置已验证
- 备份、恢复、监控、告警链路已就绪
- 平台后台与租户前台访问入口已区分

## 12. 结论
部署文档的目标不是记录某一台机器的临时连接方式，而是定义一套可重复、可审计、可交付的软件部署基线。后续无论生成实施计划、上线清单还是私有化交付说明，都应以本文档为部署上位基线。
