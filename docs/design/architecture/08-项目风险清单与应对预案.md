# 项目风险清单与应对预案

## 1. 文档目的
识别项目推进阶段和系统实现阶段的主要风险，并给出应对措施。

## 2. 业务风险
### 风险一：用户对自动化预期过高
应对：
- 首页明确区分“已自动完成”和“待确认”
- 不承诺完全无人值守

### 风险二：货源不稳定
应对：
- 主备供应商机制
- 涨价和缺货自动拦截
- 不同货源渠道独立评分与降级切换

### 风险三：营销活动利润失控
应对：
- 活动发布前利润校验
- 高风险活动必须审批
- 活动异常支持快速下线

## 3. 技术风险
### 风险四：第三方接口不稳定
应对：
- 接口限流处理
- 重试和降级
- 关键接口优先级控制

### 风险五：异步链路状态不一致
应对：
- 幂等键
- 状态机校验
- 审计日志

### 风险六：客户服务辅助建议不当
应对：
- 敏感问题转人工
- 知识库可追踪
- 高风险答案禁止自动发送

### 风险七：直播运营违规或失控
应对：
- 直播脚本预审
- 直播商品池合法性校验
- 直播异常自动停止

### 风险八：开放平台调用越权
应对：
- 应用权限最小化
- 外部应用凭据认证与 `permissionScope` 授权双重校验，当前 `/api/open/external/erp/*` 必须具备对应能力的细粒度 `scope`
- AccessKey/Secret 与 webhook secret 定期轮换
- 回调签名、时间窗、防重放校验纳入默认安全门禁
- 调用日志与异常告警必须保留 `rejected_secret`、`rejected_replay`、`rejected_scope` 等拒绝结果，便于审计抽查

## 4. 项目管理风险
### 风险九：范围持续膨胀
应对：
- 主链路优先
- 新需求纳入变更评审
- 通用底座优先复用，不重复造轮子

### 风险十：设计与开发脱节
应对：
- 页面文档、接口文档、状态机文档同步维护
- 联调问题清单持续更新
- 新增模块必须同步更新数据与测试文档

## 5. 合规与治理风险
### 风险十一：商品内容违规
应对：
- 发布前风控检测
- 高风险内容阻断

### 风险十二：售后争议升级
应对：
- 证据链归档
- 人工接管机制

### 风险十三：多组织数据隔离失效
应对：
- 组织、店铺、角色三层权限校验
- 权限测试作为上线门槛
- 敏感接口强制审计

### 风险十四：财务口径不一致
应对：
- 账单口径统一定义
- 财务对账留痕
- 指标变更走评审流程

### 风险十五：SaaS计费或订阅状态错误
应对：
- 订阅状态单一数据源
- 套餐变更和支付回调幂等
- 停复服动作全链路审计

### 风险十六：租户隔离失效
应对：
- 租户、组织、店铺三级隔离校验
- 配额与权限联动测试
- 高风险后台操作双重确认
