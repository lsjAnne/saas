## 1. 文档目的
本文档用于补充系统的数据字典口径，统一说明核心数据表的业务含义、关键字段、状态字段和使用边界。

说明：
- 完整建表 SQL、字段类型、索引和注释以 [数据库表结构设计文档](02-数据库表结构设计文档.md) 为准。
- 本文档重点回答“这张表是做什么的、关键字段是什么意思、字段口径如何统一”。
- 状态流转规则以 [状态机说明文档](../architecture/02-状态机说明文档.md) 为准。

## 2. 通用字段口径
| 字段 | 中文含义 | 口径说明 |
| --- | --- | --- |
| `id` | 主键 ID | 表内唯一主键 |
| `tenant_id` | 租户 ID | 多租户隔离最高业务边界 |
| `organization_id` | 组织 ID | 租户下的组织或团队边界 |
| `store_id` | 店铺 ID | 电商经营主体店铺唯一标识 |
| `user_id` / `owner_user_id` / `actor_id` / `approver` | 用户 ID | 系统操作人、负责人、审批人或行为发起人 |
| `status` / `*_status` | 状态字段 | 统一使用英文枚举值 |
| `created_at` | 创建时间 | 数据首次写入时间 |
| `updated_at` | 更新时间 | 数据最后修改时间 |
| `*_json` | JSON 配置字段 | 承载扩展配置、规则或结构化明细 |
| `risk_flag` / `risk_level` | 风险标记 / 风险等级 | 风控标识，不等同于业务状态 |
| `trace_id` | 追踪 ID | 贯穿接口、任务、日志与导出链路 |

## 3. 核心状态字段说明
| 字段 | 中文含义 | 说明 |
| --- | --- | --- |
| `auth_status` | 授权状态 | 店铺、渠道账号等接入对象授权有效性 |
| `plan_status` | 计划状态 | 直播计划、业务计划类对象状态 |
| `session_status` | 会话状态 | 直播会话、客户会话等运行态对象 |
| `order_status` | 订单状态 | 订单主链路状态 |
| `logistics_status` | 物流状态 | 履约回传和物流跟踪状态 |
| `ticket_status` | 工单状态 | 客服工单处理状态 |
| `subscription_status` | 订阅状态 | 租户套餐订阅状态 |
| `payment_status` | 支付状态 | 计费订单支付状态 |
| `bill_status` | 账单状态 | 财务账单状态 |
| `approval_status` | 审批状态 | 审批流转状态 |

| `subscription_plan` | 套餐定义表 | `plan_code`, `plan_name`, `billing_type`, `monthly_price`, `yearly_price`, `seat_limit` | `status` | SaaS 销售套餐及能力开关定义 |

| `billing_order` | 计费订单表 | `tenant_id`, `plan_id`, `order_type`, `payable_amount`, `external_order_no`, `paid_at` | `payment_status` | 套餐购买、续费、升级等计费订单 |
| `invoice_request` | 发票申请表 | `tenant_id`, `billing_order_id`, `invoice_title`, `invoice_tax_no` | `invoice_status` | 发票申请与开票流程对象 |
| `support_session` | 支持会话表 | `tenant_id`, `reason`, `approver`, `expires_at`, `active` | `active` | 平台支持人员临时进入租户业务详情的受控授权对象 |
| `audit_log` | 审计日志表 | `tenant_id`, `organization_id`, `store_id`, `actor_id`, `action_type`, `target_type`, `target_id`, `operation_result`, `source_module`, `support_session_id`, `trace_id` | 无独立状态 | 核心行为留痕与租户隔离追责对象 |

| `channel_account` | 渠道账号表 | `organization_id`, `channel_type`, `account_name`, `extra_config` | `auth_status` | 店铺外的渠道连接对象，如通知、平台账号、开放渠道 |
| `candidate_product` | 候选商品表 | `store_id`, `source_type`, `source_url`, `title`, `estimated_profit` | `status` | 选品阶段的候选池，不代表已上架商品 |

## 6. 标准使用方式
- 做后端开发时，先看 [数据库表结构设计文档](02-数据库表结构设计文档.md) 的 SQL 结构，再看本文档的业务口径。
- 做接口联调时，字段含义和命名口径优先按本文档与 [接口示例与字段说明](../interface/02-接口示例与字段说明.md) 保持一致。
- 做测试造数时，状态值、金额口径、时间字段和多租户边界必须按本文档执行。
- 做 BI、埋点、报表时，经营指标和财务口径要与 [埋点与经营指标口径说明](../architecture/07-埋点与经营指标口径说明.md) 联合使用。
