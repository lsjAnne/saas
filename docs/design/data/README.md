# 数据设计文档目录说明

本目录存放数据模型、库表结构、数据字典、数仓分层、指标治理和公共枚举文档，是数据库设计、数仓建设和经营分析的统一入口。

| 文档名称 | 文档类型 | 当前版本 | 适用对象 | 主要读者 | 维护状态 |
| --- | --- | --- | --- | --- | --- |
| 数据设计文档目录说明 | 目录说明 | v2.0 | 数据设计导航、数据评审、联调验收 | 产品、架构、后端、数据、测试、BI | 已整理 |

## 1. 文档职责
- 明确核心实体、表结构、字段口径、索引和状态定义。
- 建立业务库、数仓、报表和埋点之间的一致数据边界。
- 为后端研发、测试造数、BI 开发、实施验收提供统一数据基线。

说明：
- 本目录用于沉淀数据设计基线，不直接代替项目当前研发进度、模块完成度或真实环境接线状态。
- 当前阶段实际停留点、开发优先级和待收口事项以 [最终交付说明](../../overview/02-最终交付说明.md)、[从0到落地全链路开发计划](../../development/process/05-从0到落地全链路开发计划.md) 和 [SDD开发任务清单](../../development/process/06-SDD开发任务清单.md) 为准。
