## 1. 文档目的
本文档在 [接口规格文档](01-接口规格文档.md) 基础上，补充常用接口的请求响应示例、字段说明和错误返回示例，方便前后端联调与测试编写用例。

补充说明：

- 本文档用于示例对齐与测试造数，不直接承担“当前真实进度”说明。
- 示例字段与路径以接口基线为准；当前项目阶段与真实缺口请回到 `02 / 05 / 06` 三份主文档。

## 2. 通用返回结构
```json
{
  "code": 0,
  "message": "ok",
  "data": {},
  "traceId": "20260530-abc-123"
}
```

字段说明：
- `code`：业务返回码，0 表示成功
- `message`：接口说明文本
- `data`：业务数据
- `traceId`：本次请求追踪 ID

### 11.3 直播状态查询接口
`GET /api/live-sessions/18001/status`

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "livePlanId": 13001,
    "liveSessionId": 18001,
    "planStatus": "running",
    "sessionStatus": "running",
    "controlMode": "enhanced",
    "currentSceneCode": "FLASH_SALE",
    "nextSceneCode": "RETURN_SHOW",
    "currentProductId": 9001001,
    "currentProductTitle": "夏季冰感防晒衣",
    "currentProductSourceType": "SELF_OWNED",
    "scriptVersion": 6,
    "currentSegmentCode": "SEGMENT-03",
    "commentPeakPerMinute": 186,
    "riskAlertCount": 2,
    "pendingCommitmentCount": 1,
    "manualTakeoverActive": false,
    "concurrencyRemaining": 1
  },
  "traceId": "live-session-status-001"
}
```

字段说明：
- `controlMode`：直播控场模式，取值建议为 `standard`、`enhanced`、`manual`
- `currentSceneCode` / `nextSceneCode`：当前场景和下一候选场景编码
- `commentPeakPerMinute`：最近 1 分钟评论峰值，用于是否启用强控场模式
- `pendingCommitmentCount`：待人工确认的高风险承诺数量
- `manualTakeoverActive`：当前是否处于人工接管模式

## 16. 开放平台应用创建接口
### 16.1 请求
`POST /api/open/apps`

```json
{
  "organizationId": 101,
  "appName": "ERP同步助手",
  "appType": "private",
  "permissionScope": [
    "erp.master_data.read",
    "erp.account_mapping.read",
    "erp.integration_baseline.read"
  ]
}
```

说明：
- `permissionScope` 需与应用实际访问范围一致。
- 外部 ERP 读取接口 `/api/open/external/erp/*` 现已按能力拆分 scope：主数据接口需要 `erp.master_data.read`，科目映射接口需要 `erp.account_mapping.read`，集成基线接口需要 `erp.integration_baseline.read`；缺少对应 scope 会返回 `1009` 并记录 `rejected_scope` 调用日志。

### 16.2 响应
```json
{
  "code": 0,
  "message": "created",
  "data": {
    "appId": 19001,
    "accessKey": "app_xxx",
    "secretMasked": "sec_****",
    "status": "enabled"
  },
  "traceId": "open-app-create-001"
}
```
