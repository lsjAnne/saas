# 后端开发文档目录说明

本目录存放后端服务设计、模块划分、数据库落地和 API 分期开发文档。

| 文档名称 | 文档类型 | 当前版本 | 适用对象 | 主要读者 | 维护状态 |
| --- | --- | --- | --- | --- | --- |
| 后端开发文档目录说明 | 目录说明 | v1.1 | 后端开发目录导航 | 架构、后端、测试 | 已整理 |

## 文档用途
- 指导后端应用分层、领域服务、任务调度和审计链路实现。
- 明确数据库实施顺序、DDL 执行范围和接口迭代节奏。
- 为后端团队拆分任务、安排联调和控制交付节奏提供依据。

## 文件清单
- [后端服务开发文档](01-后端服务开发文档.md)：后端服务分层、领域建模、任务编排和审计设计。
- [后端模块目录设计文档](02-后端模块目录设计文档.md)：当前真实后端代码树、模块分组、包结构和新增代码落位规则。
- [数据库落地清单文档](03-数据库落地清单文档.md)：数据库分阶段落地和验收清单。
- [API分期开发清单文档](04-API分期开发清单文档.md)：API 分期开发节奏和依赖关系。

## 推荐阅读顺序
1. 先看 [SDD开发设计文档](../../design/architecture/10-SDD开发设计文档.md)。
2. 再看 [后端服务开发文档](01-后端服务开发文档.md) 和 [后端模块目录设计文档](02-后端模块目录设计文档.md)。
3. 数据库实施前看 [数据库落地清单文档](03-数据库落地清单文档.md)。
4. 迭代排期时看 [API分期开发清单文档](04-API分期开发清单文档.md)。
