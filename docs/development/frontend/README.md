# 前端开发文档目录说明

本目录存放前端工程设计和页面实现约束文档。

| 文档名称 | 文档类型 | 当前版本 | 适用对象 | 主要读者 | 维护状态 |
| --- | --- | --- | --- | --- | --- |
| 前端开发文档目录说明 | 目录说明 | v1.1 | 前端开发目录导航 | 产品、前端、测试 | 已整理 |

## 文档用途
- 明确前端工程结构、路由、状态管理和组件组织方式。
- 统一接口接入、权限控制、埋点和异常态处理要求。
- 为页面开发、联调和回归测试提供实现依据。

## 文件清单
- [前端工程设计文档](01-前端工程设计文档.md)：前端模块划分、工程组织、页面实现约束和联调要求。
- [前端组件架构与状态流转文档](02-前端组件架构与状态流转文档.md)：组件树、状态流、查询缓存和高交互页面架构。

## 推荐阅读顺序
1. 先看 [原型与交互文档目录说明](../../requirements/prototype/README.md) 理解页面与交互。
2. 再看 [前端工程设计文档](01-前端工程设计文档.md) 进行工程落地。
3. 再看 [前端组件架构与状态流转文档](02-前端组件架构与状态流转文档.md) 对齐状态流与组件边界。
4. 联调前同步阅读 [接口设计文档目录说明](../../design/interface/README.md) 和 [测试与验收文档目录说明](../../development/testing/README.md)。
