## 2. 系统边界与纳入范围

### 2.1 总体定位

- 本项目的 `SaaS` 是交付模式，不是独立业务系统名称。
- 本项目定位为一套可按标准 SaaS 版和私有化版交付的多租户电商经营平台。
- 平台核心系统边界按 `SaaS 平台底座 + OMS + SRM + ERP 基础能力 + CRM + WMS/TMS + BI + 开放平台/治理` 组织。
- 审批、通知、支持会话、审计、导出、退租治理归入平台治理域，不单独拆成孤立系统。
- ERP / WMS / TMS / BI 采用“核心能力自研优先、外部集成为后置增强”的研发路线，当前代码已具备继续自研演进的主链路基础。

## 5. 分系统实施顺序与依赖关系

1. 先完成 `阶段 8`：SaaS 商用化与合规底座。

### 5.3 可开工边界结论

- 文档层面：已达到可直接指导研发、联调、测试和交付准备的成熟度。
- 计划层面：已完成阶段顺序、批次划分、岗位责任和依赖门槛定义。
- 环境层面：`JDK 21` 与 `mvn test` 复核已完成，不再是当前阻塞项。
- 外部资源层面：第三方联调账号、消息网关、财税接口、开放平台沙箱尚未逐项验收。
- 结论：可以立即进入阶段 8 的任务拆分、研发排班和实现准备；不建议在环境复核与外部资源未补齐前宣告“全阶段全面开工”。
