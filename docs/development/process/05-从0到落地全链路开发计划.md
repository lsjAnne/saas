## 2. 当前总状态

- `001-260` 主线功能已经完成到“本地可开发、可测试、可继续扩展”的状态。
- 项目当前不是“从零开发阶段”，而是“主链路完成后的增强与交付阶段”。
- 当前主线重心已经从内部模块补齐，切换到阶段 13：
  - 外部系统接线
  - 可观测性
  - 交付与发布
  - 双交付形态支撑

一句话结论：

> 内部业务主链路已形成闭环，当前重点不是再发散加新模块，而是把外部集成、交付门禁和真实运行接线做实。

## 3. 已完成的业务版图

### 3.1 平台底座

- 租户、组织、成员、店铺、渠道、审计、支持会话已具备基础能力。
- 认证体系已切到正式账号登录 + Bearer token。
- 权限体系、敏感操作二次确认、租户治理基础已落地。

### 3.2 电商业务主链路

- 商品、供应商、库存、补货、订单、履约、物流、售后已具备最小闭环。
- CRM、营销、通知、审批、财务、经营看板均已接入主业务流程。

### 3.3 ERP / CRM / OMS / SRM / WMS / TMS / BI

- ERP 方向：采购、收货、退货、库存台账、应收应付、凭证、发票、结账检查已具备最小闭环。
- CRM 方向：会员画像、分群、触达、SLA、联动视图已完成。
- OMS 方向：汇单、审单、拆合单、路由编排、逆向订单、工作台已完成。
- SRM 方向：准入、评级、询价、预约送货、结算协同、风险预警已完成。
- WMS 方向：仓库、入库、波次、锁库、盘点、逆向入库、联动总览已完成。
- TMS 方向：承运商、运单、轨迹、结算、签收、逆向物流、控制塔已完成。
- BI 方向：主题域、指标字典、分层、经营分析、导出、订阅、数据质量、交付检查已完成。

## 4. 当前阶段 13 已完成的增强

### 4.1 外部系统策略已定

- 采用“自研主链路优先，外部系统做增强接入”的原则。
- 当前优先吸收的成熟开源系统口径：
  - ERP：`Apache OFBiz`
  - WMS：`OpenBoxes`
  - BI：`Apache Superset`
  - 路线引擎：`OSRM`
  - 消息网关：`RabbitMQ`

### 4.2 已落代码的外部集成

- `OSRM` 已接入：
  - `POST /api/tms/external-route-plan`
  - `POST /api/tms/external-distance-matrix`
- `Superset` 只读骨架已接入：
  - `GET /api/bi/external-platform-overview`
- `OFBiz / OpenBoxes / RabbitMQ` 只读基线已接入：
  - `GET /api/open/external/erp/ofbiz-baseline`
  - `GET /api/open/external/wms/openboxes-baseline`
  - `GET /api/open/external/messaging/rabbitmq-baseline`

### 4.3 已落代码的观测与门禁

- 租户侧系统观测视图已具备：
  - `GET /api/tenant/system/observability-overview`
- 平台侧交付门禁已具备：
  - `GET /api/admin/tenants/{id}/release-readiness`
- `observability-overview`、`actuator/info`、`actuator/health` 已同步暴露：
  - `externalErpPlatform`
  - `externalWmsPlatform`
  - `externalMessagingPlatform`
- Actuator 已暴露：
  - `/actuator/health`
  - `/actuator/info`
  - `/actuator/prometheus`

### 4.4 已落代码的交付骨架

- GitHub Actions、双 compose 配置、交付 readiness 视图已具备基础骨架。
- 当前已经可以表达“配置是否齐”“门禁是否满足”，但还不等于真实外部环境已全部联通。

## 5. 当前未完成的核心事项

当前真正未完成的，不是业务模块本身，而是下面四类：

1. 外部系统真实接线
   - ERP / WMS / BI / 消息系统真实 endpoint、凭据、回调联调
2. 观测平台真实接线
   - 日志聚合、链路追踪、告警路由、dashboard
3. 交付链路真实接线
   - 镜像仓库凭据、发布密钥、灰度开关、真实环境发布
4. 双交付真实验收
   - 标准 SaaS 与私有化环境的真实验证
