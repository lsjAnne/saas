## 1. 使用说明
这份导航用于帮助项目成员快速定位正式文档，并按“交付模式、系统域、岗位职责、研发阶段”四条主线阅读。

项目当前统一口径如下：
- `SaaS` 是交付模式，不是独立业务系统名称。
- 业务系统按 `SaaS 平台底座 / OMS / SRM / ERP / CRM / WMS / TMS / BI / 开放平台` 组织。
- 模型能力属于增强层，不能替代订单、库存、采购、履约、财务、会员和治理主系统。
- 开发计划类文档仅反映当前已完成与未完成状态；架构、数据和设计类文档作为开发计划生成的上位依据。
- 直播运营中心已经形成独立系统域入口，涉及高互动控场、复杂场景切换、人工接管和高风险承诺治理时，不再按“普通脚本生成能力”理解。
