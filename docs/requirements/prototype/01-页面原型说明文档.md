## 1. 文档目的
本文档描述系统核心页面的结构、布局、模块、关键操作和用户路径，作为 UI 设计与前端实现的依据。

## 2. 设计原则
- 首页信息优先于复杂管理
- 单页只承担一个主要目标
- 风险项必须高亮且有解释
- 默认展示系统建议动作
- 支持桌面端主操作，手机端支持查看与确认
- 低频专业配置默认折叠，不干扰业务用户

## 3. 核心页面

页面目标：
- 快速完成系统登录、套餐开通、组织建立和店铺接入

页面区块：

- 组织创建区
- 平台选择区
- 店铺授权状态区

- 登录
- 开通试用
- 选择套餐
- 创建组织
- 发起授权
- 保存默认利润阈值
- 完成初始化

- 核心指标卡片区

- 风险提醒区

## 4. 用户路径
### 4.1 新用户路径
登录 -> 开通试用或选择套餐 -> 创建组织 -> 接入店铺 -> 完成初始化 -> 首页驾驶舱 -> 候选商品池 -> 商品中心

### 4.2 日常经营路径
首页 -> 查看建议动作 -> 订单与履约中心 -> 客户服务辅助页 -> 异常中心 -> 返回首页

### 4.3 营销运营路径
首页 -> 营销活动中心 -> 选择模板 -> 绑定商品 -> 提交审批 -> 发布活动 -> 查看效果

### 4.4 库存补货路径
首页库存预警 -> 库存与补货中心 -> 创建补货任务 -> 提交审批 -> 回写结果

### 4.5 财务复盘路径
首页 -> 财务结算中心 -> 生成账单 -> 对账异常处理 -> 导出结算单 -> 经营分析页

### 4.6 开放集成路径
平台管理 -> 开放平台中心 -> 创建应用 -> 配置权限与回调 -> 查看调用日志

### 4.7 SaaS订阅路径
登录 -> 订阅与计费中心 -> 选择套餐 -> 支付或续费 -> 调整席位 -> 返回经营首页

## 5. 页面设计结论
页面设计必须服务于“用户少操作”这个核心目标，同时给成熟团队预留足够的协作、管理、开放和经营扩展空间。
