## 1. 文档说明

这份文档是 `2026-06-27` 当时为“租户订阅与外部集成控制台”整理的实施计划。

它的价值在于保留当时的拆解思路，包括：

- 为什么要在仓库内补一个独立前端子工程
- 登录、后台壳子、订阅中心和外部集成偏好的最小落地顺序
- 前端工程如何按 `pages / features / services / stores` 分层

## 2. 当前口径

截至 `2026-07-04`，这份计划里的核心事项已经不应再按“待实施”理解：

1. 仓库内已经存在真实前端工程 `frontend/`。
2. 登录页、后台壳子、订阅与计费中心已经落地。
3. 租户外部集成偏好接口已经接入前端调用链。
4. 当前主要缺口不再是“有没有这个控制台”，而是“真实外部接线、真实观测、真实交付链路和治理逻辑是否完成”。

## 3. 应该如何使用这份文档

可以用它做：

- 回看前端子工程最初的拆解路径
- 复盘当时为什么选择 `Vue 3 + Vite + Pinia + Vue Router`
- 理解“订阅中心 + 外部软件可选配置”这一交互线最早的实现范围

不要再用它做：

- 判断当前项目是否还没有前端工程
- 判断当前订阅中心是否仍未开发
- 判断当前真实开发停留点
